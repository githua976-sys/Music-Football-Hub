# Music Football Hub

Music Football Hub is a modern React dashboard application that combines music and football content into one platform.

---

# Features

- Google Authentication with Firebase
- Music Dashboard
- Football Dashboard
- Favorites System
- Responsive Design
- Audio Player
- Sidebar Navigation
- Modern UI with Tailwind CSS

---

# Technologies Used

## Frontend
- React.js
- Vite
- Tailwind CSS
- React Router DOM
- Context API
- Axios

## APIs
- Deezer API
- TheSportsDB API

## Authentication
- Firebase Authentication
